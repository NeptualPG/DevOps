### INCLUDE: 

1. CODE
2. RUNTIME
3. LIBRARIES
4. SYSTEM TOOLS


### WorkFlow:

Docker Client (INSTRUCTIONS)
Docker Host (DOCKER DAEMON) (MANAGER)
Docker Registry (DOCKER HUB) (REPOSITORY WHERE IMAGES ARE SAVED)

### yaml:

FROM (BASE IMAGE)
WORKDIR (SET DIR TO FOLLOW INSTRUCTIONS)
COPY (COPY FILES TO BUILD COMPONENTS TO THE IMAGE (RECEPY))
RUN (EXECUTE COMMANDS INTO THE SHELL)
EXPOSE (INFORME THE CONTAINER IS LISTENING) NETWORK PORTS
ENV (ENV VARIABLES TO RUN THIS COMMADS)
ARG (DEFINE VARIABLES AND VERSIONS) 
VOLUME (DATA OR MOUNT OF VOLUME TO CONNECT EXTERNAL STORAGE)
CMD (DEFAULT COMMANDS TO EXECUTE WHEN THE CONTAINER STARTS)
ENTRYPOINT (SPECIFIES THE DEFAULT EXECUTEABLE TO BE RUN)

ENTRYPOINT(DEFINES THE MAIN COMMANDS CAN'T BE EASILY OVERRRIDDEN) - CMD (FLEXIBLE CAN BE OVERRIDEN)
